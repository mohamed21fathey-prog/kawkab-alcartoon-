# كوكب الكرتون — النسخة الأولية
هذه نسخة واجهة أمامية تجريبية (Prototype) باللغة العربية واتجاه RTL.

## التشغيل
افتح `index.html` في المتصفح أو ارفع الملفات إلى استضافة صفحات ثابتة.

## الموجود حاليًا
- صفحة رئيسية متجاوبة مع الهاتف والكمبيوتر.
- أقسام الخدمات والمنتجات الرقمية.
- قائمة هاتفية.
- نصوص عربية أولية وهوية لونية.

## غير الموجود بعد
- تسجيل الحسابات وقاعدة البيانات.
- لوحة تحكم الإدارة.
- رفع ملفات المنتجات وحمايتها.
- الدفع الإلكتروني والتحقق من الدفع.
- توليد الفيديو والذكاء الاصطناعي.

لا تفعّل البيع أو تسلّم ملفات مدفوعة اعتمادًا على هذه الواجهة وحدها. يلزم بناء خادم آمن وربط قاعدة بيانات ودفع موثوق قبل استقبال الأموال.
