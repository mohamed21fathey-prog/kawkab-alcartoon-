# كوكب الكرتون — واجهة تجريبية مطوّرة

واجهة عربية RTL متجاوبة لمنصة كوكب الكرتون، تعمل كصفحة ثابتة دون الحاجة إلى خادم أو مفاتيح API.

## التشغيل
افتح `index.html` في المتصفح، أو انشر الملفات الثابتة على استضافة صفحات.

## الموجود في هذه النسخة
- تصميم كوني بخلفية كحلية وكوكب أزرق وحلقات مدارية.
- قائمة متجاوبة للهاتف والكمبيوتر.
- أقسام المنصة: استوديو الفيديو، مصنع الحلقات، محتوى الحضانة، شرح المناهج، التعليم للكبار، القصص والمغامرات، كتب التلوين، الألغاز والتحديات، الأغاني وقصص النوم، الإعلانات والتسويق، وإعلانات السوشيال ميديا والمتجر.
- نموذج تخطيط مشروع يعمل محليًا داخل المتصفح ويعرض ملخصًا وخطوات مقترحة.
- لا توجد خدمات توليد خارجية أو مفاتيح API في هذه الملفات.

## حدود النسخة الحالية — مهم
هذه واجهة أمامية تجريبية وليست منصة إنتاج مكتملة:
- نموذج الاستوديو ينشئ مخططًا نصيًا داخل الصفحة فقط؛ لا يولّد فيديو أو صورًا ولا يدمج ملفات.
- لا توجد حسابات مستخدمين أو قاعدة بيانات أو لوحة إدارة.
- لا يوجد نظام رصيد/كريدت أو شراء أو دفع أو تنزيل منتجات مدفوعة.
- بطاقات المتجر للعرض فقط، ولا يجوز استقبال أموال أو تسليم منتجات بناءً عليها.
- لا توجد حماية للملفات أو صلاحيات للمستخدمين.

## ما يلزم قبل الإطلاق التجاري
بناء خادم آمن وقاعدة بيانات، ونظام مصادقة وصلاحيات، وتخزين ملفات، والتحقق من المدفوعات من جهة الخادم، وسجل معاملات ورصيد موثوق، ثم دراسة أي خدمة إنتاج تختارها الإدارة بعد مراجعة التكلفة والخصوصية. لا تُضف أي خدمة مدفوعة أو مفتاح API دون موافقة صريحة.

## النشر
اختبر الفرع أولًا على معاينة منفصلة. لا تدمج هذا الفرع إلى `main` ولا تغيّر إعدادات النشر قبل مراجعة النسخة والموافقة عليها.
