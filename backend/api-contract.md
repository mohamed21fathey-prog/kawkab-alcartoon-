# عقد واجهة الخادم — مسودة غير مفعّلة

هذه الوثيقة تحدد شكل الواجهة المقترحة فقط. لا يوجد خادم منشور أو API يعمل حاليًا.

## قواعد عامة
- جميع الطلبات عبر HTTPS.
- المصادقة بجلسة آمنة من جهة الخادم أو موفر هوية معتمد بعد اختيار المستخدم.
- ملفات تعريف الارتباط المقترحة: HttpOnly, Secure, SameSite؛ لا تخزن رموز الجلسات في localStorage.
- تحقق من ملكية كل مورد وصلاحية الدور في الخادم.
- حدّد معدل الطلبات، وحجم الجسم، وأنواع الملفات المسموحة.
- لا تُرجع مفاتيح سرية أو مفاتيح تخزين للمتصفح.
- لا تقبل قيمة الرصيد أو حالة الدفع من العميل.

## المسارات المقترحة

| Method | Path | الغرض |
|---|---|---|
| GET | /api/health | فحص جاهزية الخدمة دون بيانات حساسة |
| GET | /api/me | بيانات الحساب الحالي |
| GET, POST | /api/projects | عرض مشروعات المستخدم وإنشاء مشروع |
| GET, PATCH, DELETE | /api/projects/:id | قراءة/تعديل/حذف مشروع يملكه المستخدم |
| GET | /api/projects/:id/assets | قائمة ملفات المشروع المصرح بها |
| POST | /api/uploads/presign | إصدار إذن رفع قصير العمر بعد فحص الصلاحية |
| POST | /api/orders | إنشاء طلب دفع بحالة pending |
| GET | /api/orders/:id | عرض حالة طلب يملكه المستخدم |
| GET | /api/wallet | عرض الرصيد المحسوب من سجل الحركات |
| GET | /api/wallet/ledger | سجل حركات المستخدم |
| POST | /api/admin/ledger-adjustments | تعديل إداري موثق ومصرح به فقط |

## الدفع وشحن الرصيد
- لا توجد نقطة API عامة تسمح للعميل بزيادة رصيده.
- إشعار بوابة الدفع يجب التحقق من توقيعه ومصدره على الخادم.
- استخدم معرّفًا فريدًا لمنع تكرار معالجة نفس الإشعار.
- سجّل حركة الشحن مرة واحدة فقط بعد تحقق الدفع.
- لا تسلّم منتجًا أو رصيدًا قبل التحقق الخادمي.

## توليد المحتوى
لا توجد مسارات توليد في هذه المسودة. لن يُختَر مزود أو تُستدعَ خدمة توليد قبل موافقة صريحة على التكلفة والخصوصية وآلية التشغيل.

## حالة التنفيذ
كل المسارات أعلاه مواصفات مستقبلية فقط. لا توجد مصادقة أو قاعدة بيانات متصلة أو مدفوعات أو تخزين أو عمليات توليد فعالة.
