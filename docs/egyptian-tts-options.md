# خيارات توليد صوت مصري مفتوح المصدر

تاريخ الفحص: 28 نوفمبر 2026

## القرار الحالي

لم نربط أي واجهة API مدفوعة أو خدمة توليد خارجية. واجهة الاستوديو الحالية تنشئ مسودة حوار محلية بقوالب، وتستخدم SpeechSynthesis للمعاينة فقط. لا تنتج MP3/WAV ولا تدمج الصوت آليًا في الفيديو.

## مرشح خفيف نسبيًا: KemeTone

- الرابط: https://huggingface.co/Rabe3/kemetone
- اللهجة: مصرية قاهرية.
- الترخيص المعلن: Apache 2.0.
- الحجم المعلن للأوزان: 327 ميجابايت.
- التشغيل: CPU أو CUDA، مع متطلبات Python وPyTorch ومكتبة espeak-ng.
- الصوت: صوت نسائي واحد فقط.
- يدعم إخراج WAV بمعدل 24 kHz.
- قيود: يحتاج نصًا مضبوطًا بالتشكيل لتحسين النطق، وليس مناسبًا لتعدد الشخصيات، ولا يوفّر أداءً تمثيليًا متنوعًا أو غناءً.

## مرشح متعدد الأصوات: VoiceTut-TTS

- الرابط: https://huggingface.co/mohammedaly22/VoiceTut-TTS
- اللهجة: مصرية، مع دعم مزج العربية والإنجليزية.
- الترخيص المعلن: Apache 2.0.
- الأصوات المعلنة: 19 صوتًا رجاليًا ونسائيًا.
- يدعم حفظ WAV والتدفق النصي الطويل.
- قياس النموذج المنشور يذكر نحو 2.93 GB من ذاكرة GPU في اختبار NVIDIA T4، ولذلك لا يناسب استضافة مجانية بسيطة أو تشغيلًا مضمونًا على الهاتف.

## لماذا لم نفعّل أحدهما تلقائيًا؟

1. الموقع الحالي واجهة ثابتة على استضافة صفحات، ولا يملك خادم Python أو GPU لتشغيل هذه النماذج.
2. تنزيل نموذج 327 MB إلى متصفح كل زائر يثقل الموقع ويستهلك بيانات الهاتف، ولا توجد نسخة WebAssembly مثبتة ومختبرة من هذا النموذج.
3. تشغيل نموذج متعدد الأصوات يحتاج GPU وذاكرة تشغيل، ولا يمكن ضمان خدمة مجانية دائمة أو سريعة.
4. لم تُختبر جودة النماذج على حوارات كوكب الكرتون، أو ملاءمتها للأطفال، أو ثبات الشخصيات الصوتية في حلقات طويلة.

## التوصية

ابدأ بتجربة KemeTone محليًا كإثبات مفهوم لصوت الراوي النسائي المصري، ثم قارن VoiceTut إذا توفر جهاز GPU مناسب لتعدد الأصوات. لا تُرفع ملفات المستخدمين إلى خدمة عامة، ولا يُفعّل أي استضافة أو API أو خدمة مدفوعة قبل موافقة صاحب المشروع. بعد نجاح الاختبار، يمكن إضافة تصدير WAV ثم ربطه بأداة دمج الفيديو.

## شروط قبول محرك الصوت

- صوت مصري طبيعي، مع نطق سليم للأسماء والكلمات العربية.
- ثبات الصوت لكل شخصية بين المشاهد.
- إمكانية حفظ WAV/MP3 من دون اشتراك أو رصيد مدفوع.
- تقسيم النص الطويل واستكمال المقاطع دون تقطيع مسموع.
- معالجة أخطاء النطق وتعديل التشكيل يدويًا.
- اختبار الأداء على هاتف متوسط واتصال إنترنت محدود.
- مراجعة الترخيص وحقوق الصوت وبيانات التدريب قبل الاستخدام التجاري.
