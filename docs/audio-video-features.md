# الصوت العربي ومختبر الأغاني ودمج الفيديو — نطاق التنفيذ

## ما أصبح متاحًا في الواجهة التجريبية
- ألعاب المتصفح تستخدم مؤثرات قصيرة مولدة محليًا عبر Web Audio API: نقرة، إجابة صحيحة، إجابة خاطئة، وإكمال اللعبة.
- يمكن إيقاف المؤثرات أو تشغيلها من صفحة الألعاب.
- زر قراءة التعليمات يستخدم SpeechSynthesis بصوت عربي إن توفر على جهاز الزائر.
- الاستوديو يتيح معاينة قراءة فكرة المشروع بالعربية، ويقبل «أغنية عربية» كنوع مشروع تخطيطي.
- هذه الوظائف لا تحتاج ملفات صوتية خارجية أو مفاتيح API أو رصيد مدفوع.

## حدود الصوت الحالية
- أصوات Web Audio مؤثرات بسيطة وليست مكتبة مؤثرات احترافية.
- SpeechSynthesis يعتمد على الأصوات العربية المثبتة في المتصفح/نظام التشغيل؛ قد لا يتوفر صوت عربي على بعض الأجهزة.
- القراءة الصوتية معاينة داخل المتصفح فقط. لا يتم إنشاء ملف MP3/WAV ولا دمج التعليق الصوتي داخل فيديو.
- لا يوجد حاليًا توليد موسيقى أو غناء آلي أو إنتاج أغنية نهائية. نوع «أغنية عربية» يحفظ فكرة المشروع فقط.

## تصميم ميزة الأغاني المستقبلية
1. مدخلات: فكرة الأغنية، الفئة العمرية، المناسبة، اللهجة/الفصحى، الأسلوب، المدة، سرعة الإيقاع، أصوات المغنيين.
2. مخرجات نصية: عنوان، لازمة، مقاطع، توزيع زمني، وتوجيهات موسيقية.
3. مراجعة حقوق الكلمات واللحن والأصوات، ومنع تقليد أصوات أشخاص حقيقيين دون موافقة.
4. إنتاج صوتي قابل للتصدير فقط بعد اعتماد مسار توليد مجاني فعلي أو موافقة صريحة على مزود آخر. لا تضاف أي خدمة مدفوعة أو مفتاح API دون موافقة المالك.

## دمج الفيديو — متطلب أساسي غير منجز
- واجهة اختيار وترتيب عدة مقاطع، معاينة الترتيب، انتقالات اختيارية، وإضافة تعليق صوتي وموسيقى ومؤثرات.
- تصدير MP4 مع اختيار الدقة ونسبة الأبعاد.
- دراسة FFmpeg.wasm للمعالجة المحلية دون رفع الملفات أو استهلاك رصيد API؛ لكنه كبير الحجم وقد يكون بطيئًا ويستهلك ذاكرة الهاتف، ويحتاج اختبارًا على الهواتف الضعيفة.
- بديل المعالجة الخادمية يحتاج Worker/خادم وموارد تخزين ومعالجة، ولا يُنشأ قبل موافقة المالك ومراجعة التكلفة والحدود.
- لا تعرض المنصة زر دمج على أنه يعمل قبل تنفيذ محرك الدمج واختباره فعليًا.

## قيود الأمان والخصوصية
- لا ترفع الملفات الصوتية أو الفيديو تلقائيًا.
- لا تستخدم KIE.ai أو أي مزود توليد مدفوع بديل.
- لا تخصم أرصدة مقابل المعاينة المحلية.
- لا تدمج التغييرات إلى main أو تنشرها للموقع الأساسي دون مراجعة وموافقة.
